# E-Commerce Sales & Profitability Analytics

## Project Overview
An end-to-end data analytics project analyzing e-commerce sales, profitability, customer behavior, product performance, regional trends, and the relationship between discounts and profit.

## Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** MySQL
- **Power BI:** Interactive dashboards and KPI reporting
- **Dataset:** Superstore sales dataset

## Project Workflow
1. Data understanding and quality checks
2. Data cleaning and feature engineering using Python
3. Exploratory data analysis (EDA)
4. SQL-based business analysis
5. Interactive Power BI dashboards
6. Business insights and recommendations

## Key Findings
- Total sales: approximately **$2.30 million**
- Total profit: approximately **$286.40K**
- Overall profit margin: **12.47%**
- Technology had the highest category profit, while Furniture had a much lower profit margin.
- The Central region had the lowest regional profit margin.
- Higher discount groups were associated with lower profitability, with the 30%+ discount group generating a substantial loss.

## Note
This project uses historical Superstore data for analytical and educational purposes. Findings describe this dataset and should not be interpreted as universal business rules.
